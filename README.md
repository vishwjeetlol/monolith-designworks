# monolith.designworks — 3D Portfolio & Interactive Space

> An interactive 3D portfolio and spatial website for **Vishwjeet Chavan** — Designer, Developer & Independent Publisher.
> Live at: **[https://monolith-designworks.vercel.app](https://monolith-designworks.vercel.app)**

---

## 🌟 Highlights
- **High-Density 3D Scan**: Full-resolution scan with live cursor-following eye tracking.
- **Cinematic Scroll Choreography**: 6 calibrated focal camera stops orbiting across features, custom stickers, and spatial profiles.
- **Physical Stickers (Normal-Aligned)**:
  - `MONOLITH.DESIGNWORKS` — Independent practice emblem
  - `BLENDER 3D` — Spatial modeling & generative 3D
  - `THREE.JS / WEBGL` — Creative development badge
  - `CHATPATI EDITION` — Vibrant starburst badge (monolith.zine signature aesthetic)
  - `404` — Playful hacker text sticker
  - `RAINBOW CD` — Iridescent disc (music criticism & physical media)
  - `WIN98 CURSOR` — Pixel pointer
- **Curated Works Showcase**:
  - **Books & Cultural Publishing**: *A Caterpillar's Requiem (TPAB)*, *Inside Is Not an Exit (Bo Burnham)*, *Can We Get Much Higher (MBDTF)*, and *Monolith Chatpati Edition* with featured showcase video and concept art wraps.
  - **Blender & 3D Artwork**: Y2K 3D Flip Phone interface, Charli XCX cassette packaging archive, and spatial objects.
  - **Creative Web & Development**: Screen recording walkthrough, HeatAtlas (Urban Heat Island Visualizer), Indian Bazaar Panoramic Portfolio, and MineGuard (Smart India Hackathon).

---

## 🛠 Tech Stack
- **Framework**: React 18, TypeScript, Vite
- **3D & Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), `@react-three/drei`, `@react-three/postprocessing`
- **Audio & Interactions**: Web Audio API, Framer Motion
- **3D Modeling & Animation**: Blender 5.4, glTF 2.0
- **Hosting & CI/CD**: Vercel Global Edge CDN

---

## 🚀 Local Development
```bash
cd web
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
