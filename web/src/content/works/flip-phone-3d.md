# Y2K 3D Flip Phone Interface

![Flip Phone Call States](/works/blender/flip_phone.png)

A detailed 3D study and playful interactive interface exploring early 2000s mobile phone form factors, typography, and hardware interaction.

- **Modeling**: Precision sub-d modeling in Blender with tactile plastic shells, antenna detailing, and physical keypad geometries.
- **Interface States**: Visualized call flows including incoming caller ID ("Dani, Front Row"), live connected call timer, and missed/declined states.
- **Visual Style**: Low-fi LCD matrix aesthetic, retro UI icons, and tactile nostalgia.
